# Auditoria LGPD

## Eventos a Registrar

O Sistema Bom Samaritano deve registrar eventos relevantes relacionados a dados pessoais:

- Inclusao de dados
- Alteração de dados
- Exclusao de dados
- Exportação de dados
- Visualização de dados sensíveis
- Revogação de consentimento
- Solicitação de exclusão ou anonimização

## Campos Recomendados

- Data e hora
- Usuário responsável
- Perfil do usuário
- Modulo afetado
- Tipo de ação
- Identificador do registro
- Origem da solicitação
- Justificativa, quando aplicavel

## Uso

Os registros de auditoria devem apoiar verificações internas, investigação de incidentes, atendimento a titulares e melhoria da segurança do sistema.
