# Controle de Acesso

## Perfis

### Pastor

Acesso total aos módulos e configurações.

### Secretária

Acesso administrativo limitado a cadastros, comunicações e organização operacional.

### Obreiro

Acesso somente aos cadastros autorizados.

### Líder

Acesso restrito ao seu grupo, celula ou ministerio.

## Dados Sensiveis

Pedidos de oração, aconselhamento, informações familiares, dados de crianças, dados financeiros e históricos pastorais devem possuir acesso restrito.

## Boas Praticas

- Usar contas individuais.
- Evitar compartilhamento de senhas.
- Remover acesso de usuários desligados.
- Revisar permissoes periodicamente.
- Registrar eventos relevantes em auditoria.
