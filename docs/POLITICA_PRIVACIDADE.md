# Política de Privacidade

O Sistema Bom Samaritano - CRM Pastoral trata dados pessoais para fins pastorais, administrativos, ministeriais e de comunicação institucional da igreja.

## Dados Tratados

Podem ser tratados dados de membros, visitantes, crianças, jovens, responsáveis, discipulado, batismo, certificados, mensagens e registros financeiros relacionados à igreja.

## Uso dos Dados

Os dados são utilizados para cadastro, acompanhamento pastoral, organização de ministérios, emissão de certificados, comunicação autorizada e gestão administrativa interna.

## Compartilhamento

Os dados não devem ser vendidos ou compartilhados com terceiros para fins comerciais. Eventual compartilhamento operacional deve ocorrer somente quando necessário, autorizado e protegido.

## Direitos do Titular

O titular pode solicitar acesso, correção, exclusão, bloqueio de contato, revogação de consentimento ou anonimização dos seus dados.

## Seguranca

O sistema deve manter controles de acesso, autenticação, auditoria, proteção de backups e proibição de envio de dados reais para repositórios públicos.
