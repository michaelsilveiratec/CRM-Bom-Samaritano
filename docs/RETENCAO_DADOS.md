# Retencao de Dados

## Objetivo

Definir critérios para conservação, revisão, exclusão e anonimização de dados pessoais tratados pelo Sistema Bom Samaritano.

## Retencao Recomendada

- Cadastros ativos: enquanto houver relacionamento pastoral ou administrativo.
- Visitantes sem continuidade: revisar periodicamente e excluir ou anonimizar quando não houver mais finalidade.
- Certificados emitidos: manter registro mínimo necessário para validação.
- Dados financeiros: manter conforme obrigacoes administrativas, contabeis ou legais da igreja.
- Pedidos de oração e aconselhamento: manter pelo menor tempo necessário e com acesso restrito.

## Revisao Periodica

A administração deve revisar cadastros antigos, contatos bloqueados, visitantes inativos e dados sensíveis sem finalidade ativa.

## Exclusão e Anonimização

Solicitações de exclusão, revogação de consentimento e anonimização devem ser registradas e tratadas com prioridade.
