# Termo de Consentimento para Tratamento de Dados

Autorizo o Sistema Bom Samaritano - CRM Pastoral a registrar e tratar meus dados pessoais para finalidades pastorais, administrativas, ministeriais, de comunicação institucional e organização interna da igreja.

## Dados Autorizados

Autorizo o tratamento de dados como nome, telefone, WhatsApp, e-mail, endereço, data de nascimento, estado civil, informações ministeriais, histórico de discipulado, batismo, certificados, fotografias e demais informações fornecidas voluntariamente.

## Criancas e Adolescentes

Quando o cadastro envolver crianças ou adolescentes, o consentimento deverá ser dado pelo responsável legal.

## Revogação

Estou ciente de que posso solicitar a revogação deste consentimento, bloqueio de contato, exclusão ou anonimização dos meus dados, observadas obrigações legais e administrativas aplicáveis.
