# LGPD - Diretrizes do Sistema Bom Samaritano

## Objetivo

Garantir a proteção dos dados pessoais tratados pelo Sistema Bom Samaritano, em conformidade com a Lei Geral de Proteção de Dados (Lei nº 13.709/2018).

## Dados Coletados

O sistema poderá armazenar:

- Nome completo
- Telefone
- WhatsApp
- E-mail
- Endereço
- Data de nascimento
- Estado civil
- Informações ministeriais
- Historico de discipulado
- Historico de batismo
- Certificados emitidos
- Fotografias
- Dados de crianças e responsáveis
- Pedidos de oração
- Informações financeiras relacionadas a igreja

## Finalidade do Tratamento

Os dados sao utilizados exclusivamente para:

- Cadastro pastoral
- Acompanhamento de visitantes
- Consolidação espiritual
- Discipulado
- Batismo
- Emissao de certificados
- Comunicação institucional da igreja
- Organização administrativa e ministerial

## Consentimento

Todo cadastro deverá possuir consentimento expresso do titular dos dados ou de seu responsável legal.

O consentimento deverá registrar:

- Data
- Hora
- Usuário responsável
- Origem do consentimento

## Controle de Acesso

O acesso aos dados será realizado conforme perfil:

### Pastor

Acesso total.

### Secretária

Acesso administrativo limitado.

### Obreiro

Acesso apenas aos cadastros autorizados.

### Líder

Acesso restrito ao seu grupo.

## Dados Sensíveis

Pedidos de oração, informações familiares, aconselhamento e demais informações pastorais deverão possuir acesso restrito.

## Auditoria

O sistema deverá registrar:

- Inclusao de dados
- Alteração de dados
- Exclusão de dados
- Exportação de dados
- Visualização de dados sensíveis

## Exclusão e Anonimização

O titular poderá solicitar:

- Exclusão de dados
- Bloqueio de contato
- Revogação do consentimento
- Anonimização dos registros

## Seguranca

O sistema deverá:

- Utilizar autenticação de usuários
- Registrar logs de auditoria
- Proteger backups
- Restringir acessos por perfil
- Não expor dados em repositórios públicos

## GitHub

E proibido armazenar em repositórios públicos:

- Banco de dados real
- Planilhas de membros
- Dados financeiros
- Arquivos de backup
- Arquivos `.env`
- Dados pessoais de visitantes e membros

Somente código-fonte poderá ser versionado.
